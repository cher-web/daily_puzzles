# Daily Puzzles

A mobile app where long-distance couples and friends create personalized puzzles for each other. Users send messages, voice notes, or photos — AI transforms them into mini puzzles for their partner to solve, revealing the original content as a reward.

## Key Docs

- `docs/PRODUCT.md` — product spec, features, and user flows
- `docs/DATA_MODEL.md` — data model and key entities

## Principles

- Keep it simple — one meaningful exchange per day
- The reveal IS the reward — solving unlocks something personal
- Low effort to create, fun to solve
- Don't overcomplicate — ship the smallest useful version first
